# Popote 🍳

Recettes adaptées à ton objectif (prise de masse, maintien, sèche), à ta cible de protéines par repas, à ton budget, à tes appareils et à tes allergies. Les portions s'ajustent automatiquement pour atteindre ta cible de protéines. Favoris et liste de courses inclus.

Tout est enregistré sur le téléphone (localStorage), rien n'est envoyé à un serveur.

Les valeurs nutritionnelles et les prix sont des estimations à partir de moyennes (supermarché, France).

## Lancer en local
```bash
npm install
npm run dev
```
